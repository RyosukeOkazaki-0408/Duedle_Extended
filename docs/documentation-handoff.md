## 説明上の注意

- 「一覧を隠す」と選択した課題の非表示を区別する。非表示はMoodleの課題や提出物の削除ではない。
- 4つのカラーモードは単一選択、iOS風モードは独立したON/OFF。
- 自動更新はログイン済みMoodleの表示中に動作する。常時取得、OS通知、Duedle独自の端末間同期として説明しない。
- 一覧は取得時点の情報。期限・提出・成績の最終確認はMoodle本体で行う。
- Safariでの一時的なリンク遷移の問題は原因未特定。解消済みとは記載しない。
- OSのビルド下限と実機確認済みの範囲を区別する。

文章の更新時は、実際のボタン名、目次の移動先、問い合わせURL、狭い画面での表示を確認する。関連するブラウザテストは `tests/browser-support.cjs`。本文のみの変更で全機能の回帰テストを繰り返す必要はない。
