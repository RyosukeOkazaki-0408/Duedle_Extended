# オフラインの開発用拡張

```sh
python3 scripts/prepare_debug.py
```

Chromeの拡張機能管理から `build/debug/` を「パッケージ化されていない拡張機能」として読み込み、詳細の「拡張機能のオプション」を開く。通常版と名称・読込先が異なる別拡張である。Moodleのページを開く必要はない。

## 分離

- 通信は `dev/fixtures.js` のメモリ内応答のみ。Moodleのホスト権限とコンテントスクリプトは持たず、CSP `connect-src 'none'` で外部接続も禁止。
- 保存キーはすべて `duedle-debug:` 以下。設定の `sync` もこの開発用ローカル領域に置き換える。本番の課題・設定・ログイン情報を読まず、リセットではこの接頭辞だけを削除する。
- OS通知の権限・処理は本番・開発用のどちらにも存在しない。
- 通常版の `src/` とSafari用の `safari/build/extension/` に `dev/` は含まれない。

## 操作

- 通常の「課題情報を更新する」は本番の3時間クールダウンを通る。
- 「クールなし手動更新」は開発用クールダウンだけを解除して同じボタンを実行する。
- 「自動更新を今実行」は予定の待機だけを解除する。取得対象選択、排他、1回最大2ページ・8詳細、分割取得は本番コードのまま。
- 時刻を進める操作は共有の仮想時刻を変更する。3・12・24時間、55・75分、締切の境界を確認できる。通常のスケジューラーも動作する。長時間の前進では通常どおり再開時のランダム待機に入る。
- 同じ画面を別タブで開き、同時更新・非表示化・再開を確認する。更新中に別タブへ移ると、自動取得は中断し、続きが保存される。
- 通常、新規追加、締切変更、提出済み、成績変更、0件、105件ページング、ログイン切れ、HTTP 503・429、保存失敗を切り替える。
- 提出状況や成績は一覧APIの変化だけで即時検知できるとは限らない。シナリオ切替後、通常の詳細取得間隔を経過させるか、手動更新して確認する。
- 診断にはリクエスト件数・時刻、課題の詳細鮮度・再取得間隔、順番待ちと変更候補、予定、ロック、最新取得結果を表示する。ログは実Moodleのデータを含まない。

CSEの実タブ収集はこのオフライン画面では使わない。別タブ収集の保存・排他・失敗時の後始末は回帰テストで検証し、実Moodleでは別途確認する。

## 検証と除去

```sh
python3 scripts/check_extension.py
```

任意のブラウザ検証は、Playwrightが使えるNode環境で `node tests/browser-debug.cjs`。本番の初期表示も検証する場合は `node tests/browser-production.cjs`。先に開発用拡張を生成する。`CHROME_PATH` でChrome実行ファイルを指定できる。

デバッグ環境の除去は開発用拡張をブラウザから削除し、`build/debug/` を削除する。ソースから除去する場合は `dev/` と `scripts/prepare_debug.py`、開発用ブラウザテストを削除する。本番コードから開発用コードへの依存はない。
