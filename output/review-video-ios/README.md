# Duedle iOS 審査用動画

`Duedle-iOS-review-captioned.mp4` が日英字幕を焼き込んだ動画です。約3分20秒、約21MB、666×1664、30fps、H.264形式です。元動画に音声はありません。

操作内容に合わせて27区間の日英字幕を付け、元の画面を隠さないよう画面下に字幕用の余白を追加しています。右上のプロフィール画像は不透明なマスクで覆っています。機能拡張の管理画面とヘルプ画面では、操作・説明を隠さないようマスクを外しています。

元動画は変更していません。映像のカットや再生速度の変更は行っていません。拡張機能のコードにも変更はありません。

日本語・英語のSRT字幕、編集用ASS、字幕データJSON、書き出し用フィルターを同梱しています。

全編のデコードエラーがないことを確認し、字幕・マスク・機能拡張の切り替え画面・設定メニュー・ヘルプ画面を画像で確認しています。OCR検査の結果などは `validation.json` を参照してください。

元動画を毎秒2枚、計404枚でOCR検査し、対象の氏名・学籍番号の検出はありませんでした。OCRは目視確認を補助する検査です。
