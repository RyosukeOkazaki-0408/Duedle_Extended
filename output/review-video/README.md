# Duedle 審査用動画

- `Duedle-review-captioned.mp4`: 日英字幕を焼き込んだ審査用動画。元動画に音声はありません。
- `Duedle-review.ja.srt` / `Duedle-review.en.srt`: 出力動画と同期した字幕ファイル。
- `Duedle-review.ass`: 焼き込み字幕の編集用原稿。
- `captions.json` / `render-filter.txt`: 字幕の時刻・内容と書き出し条件。

元動画は変更していません。氏名・学籍番号が見える冒頭の右上は不透明なマスクで覆い、有効化後はプロフィール画像を覆っています。ぼかしと異なり、マスク内に元の文字は残りません。164.0〜166.5秒のページソースへの一時的な切り替わりは、個人情報の映り込みを避けるため削除しています。操作速度は変更していません。出力は横1920ピクセル・30fpsで、操作を隠さないよう画面下に字幕専用の余白を追加しています。

## 無効化直後の表示崩れ

2本目では、Safari設定でDuedleを無効にした後、テーマと追加UIのCSSが外れる一方、JavaScriptが追加した課題一覧・フィルター・設定メニューなどがページ内に残っています。

コードでも、`src/storage/display/filter.js` の `#ext_dashboard` の挿入、`src/theme/main.js` の設定メニュー、`src/common/navigation.js` の既存要素の削除など、複数箇所がページを変更しています。無効化後に追加UIだけを隠しても元のMoodleを完全には復元できず、正常な復元にはこれらを含む停止処理の設計とSafari上での切り替え検証が必要です。

他機能への影響がある修正なら現状維持、という依頼に従い、アプリのコードは変更していません。回避策は、Duedleを無効にした後にMoodleページを再読み込みすることです。この回避策の実機検証は今回行っていません。

## 出力の確認

約3分11秒・約36MB。全編のデコードエラーなし。字幕・マスク・設定ボタンの視認性・カット部分を画像で確認済み。元動画の右上を毎秒10枚、計1,938枚でOCR確認し、冒頭16秒以降に氏名・学籍番号の検出はありませんでした。OCRは目視確認を補助する検査です。詳細は `validation.json` を参照してください。
